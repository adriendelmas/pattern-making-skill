# ISO 4916 seam classes {#iso-4916-seam-classes}

- **Aliases**: seam types by ISO 4916, classes SS LS BS FS OS EF; fr: classification des coutures ISO 4916
- **Family**: ISO classification
- **Recognize**: a seam is named by a class (how the plies meet) and a letter variant, then the stitch rows
- **Pieces**: not applicable; the pattern carries the allowance of the seam type
- **Shape**: ISO 4916 groups seams by how the fabric edges meet: class 1 superimposed (SS, plies one over the other); class 2 lapped (LS, plies overlap and are stitched through the overlap; flat-felled seams belong here); class 3 bound (BS, an edge wrapped in a separate strip); class 4 flat or butted (FS, edges brought together and joined by a cover stitch); class 5 ornamental (OS); class 6 edge finishing (EF); classes 7 and 8 cover attaching separate items and single-ply seams. Source: class names from a secondary source (Coats bulletin, via a web search result); the letter suffixes (SSa, LSc and so on) and numbers were not verified, so do not quote them without checking the standard.
- **Drafting**: use ST section 1.1 for the allowance of each seam type. Map: plain seam -> SS; lapped and felled seams -> LS; bias binding -> BS; flatlock -> FS; hem -> class 6 or 8.
- **Sewing order**: not applicable.
- **Finishes and notions**: see ST.
- **Fabrics**: not applicable.
- **Fit faults**: not applicable.
- **Variants**: stitch classes #stitch-301, #stitch-401, #stitch-504.
- **CLO3D**: not available.
- **Confidence**: class names verified in one secondary source; letter codes unverified. ISO 4916:1991 is current (last reviewed 2022, per ISO catalogue).
- **Status**: unverified
