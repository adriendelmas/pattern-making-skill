# ISO 4915 stitch 401: two-thread chainstitch {#stitch-401}

- **Aliases**: double locked chainstitch, chain stitch, 401; fr: point de chaînette double, point de chaînette 2 fils
- **Family**: ISO 4915 stitch types, class 400 (multi-thread chainstitches)
- **Recognize**: on the face a line like a lockstitch, on the underside a braided chain of looper thread; stretches more than 301; unravels only from one end
- **Pieces**: no special piece
- **Shape**: no change to the seam allowance; used with a felling folder for flat-felled seams (jeans side seams, 4-needle machines make multiple 401 rows). Source: unverified.
- **Drafting**: follows the seam type; flat-felled seam 1.5 cm both sides, or 2 to 2.5 cm on the fell side (ST section 1.1).
- **Sewing order**: long runs without bobbin changes (side seams, inseams, shirt seams).
- **Finishes and notions**: looper thread on cones.
- **Fabrics**: denim, twill, workwear, shirt wovens.
- **Fit faults**: seam unravels -> backstitch or cross the seam end with another seam.
- **Variants**: 516 (401 + 504), 406 (coverstitch), #machine-chainstitch.
- **CLO3D**: not distinguished; set the topstitch distance.
- **Confidence**: from memory, consistent with the A&E and Coats guides.
- **Status**: unverified
