# ISO 4915 stitch 301: lockstitch {#stitch-301}

- **Aliases**: lockstitch, straight stitch, plain stitch, 301; fr: point navette, point droit
- **Family**: ISO 4915 stitch types, class 300 (lockstitches)
- **Recognize**: an identical line of stitching on both sides, each stitch locked by an upper needle thread and a bobbin thread inside the layers; the default stitch of the home machine
- **Pieces**: no special piece
- **Shape**: no stretch; it does not finish the edge, so woven seams need a separate edge finish (overlock, pinking, binding). Stitch density 4 to 5 per cm (ST section 9). Source: unverified (class definition; density from ST).
- **Drafting**: SA 1 to 1.5 cm for a plain seam, 1.5 to 2 cm at a zip, topstitch stitch length 3 to 3.5 mm (ST section 0).
- **Sewing order**: standard.
- **Finishes and notions**: needle by fabric (#needles-by-fabric), polyester or cotton thread (#threads-by-fabric).
- **Fabrics**: wovens; poor on stretch (stitches break), use the zigzag lockstitch 304 or a stretch stitch.
- **Fit faults**: puckering -> tension, stitch length, needle size; broken thread in stretch -> change to 401, 504, 602 or zigzag.
- **Variants**: 304 zigzag lockstitch; 315 multi-step zigzag (stretch stitch); #machine-lockstitch.
- **CLO3D**: the default topstitch is lockstitch-like; set the style in the GUI.
- **Confidence**: from memory, consistent with the A&E, Coats and Kohl's ISO sheets; density from ST.
- **Status**: unverified
