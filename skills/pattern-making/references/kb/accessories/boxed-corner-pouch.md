# Boxed-Corner Pouch {#boxed-corner-pouch}

- **Aliases**: zip pouch with a flat bottom, make-up bag, pencil case, boxed bag; fr: trousse a fond plat
- **Family**: bag, small, flat bottom
- **Recognize**: a pouch with a flat base and a triangular fold at each bottom corner; stands up.
- **Pieces**: outer front and back (x2), lining (x2), zipper (x1), interfacing (x2), optional tab.
- **Shape**: derived geometry (technique sheet 3.2). Draw two rectangles of width W + 20 and height Ht + c + 20, with c = D/2. After the side and bottom seams are sewn, cut a square c x c at each bottom corner of the stack, then sew the cut edges together (side seam on bottom seam) to form the box: depth D = 2c; the finished bottom width is the panel width minus 2c. The top edges receive the zipper.
- **Drafting**: 1. Choose W, Ht, D. 2. c = D/2. 3. Panels W + 20 x Ht + c + 20. 4. Sew sides and bottom; sew the corners. 5. Zip between the top edges.
- **Sewing order**: interface, zip to outer and lining, sew the sides and bottom, box the corners, turn.
- **Finishes and notions**: zipper, tab, lining.
- **Fabrics**: cotton, canvas, waxed cotton, coated cotton.
- **Fit faults**: corners twist (match seams), too shallow (increase c).
- **Variants**: #gusseted-tote, #tote-bag, #clutch.
- **CLO3D**: sew the bottom corners with segment sewing after cutting; stiff fabric.
- **Confidence**: geometry exact.
- **Status**: practice
